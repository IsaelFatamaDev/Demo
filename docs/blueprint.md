# **App Name**: EsquemaDB

## Core Features:

- Input de Definición: Permite al usuario ingresar la definición de la base de datos en un formato específico.
- Validación y Esquema JSON: Valida la entrada del usuario y genera un esquema JSON correspondiente.
- Generación de Tabla HTML: Transforma el esquema JSON en una tabla HTML visualmente organizada.
- Estructura de Base de Datos MongoDB: Ofrece una estructura predefinida basada en la entrada del usuario, específicamente para MongoDB.

## Style Guidelines:

- Primary color: Soft blue (#A0C4FF) to reflect reliability and clarity.
- Background color: Very light blue (#F0F8FF), almost white, for a clean and readable interface.
- Accent color: A slightly darker blue-purple (#BDB2FF), analogous to the primary but more saturated, for interactive elements.
- Body and headline font: 'Inter' sans-serif font for clean and modern readability.
- Use simple, line-based icons for clarity and ease of understanding.
- Maintain a clear separation between the input and output sections using a grid layout.
- Provide smooth transitions and loading animations for a polished user experience.
